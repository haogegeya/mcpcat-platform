# MCPCat Data Skill

MCPCat 是一个 MCP 数据聚合网关，一个端点提供多个领域的实时数据查询工具。

## 使用前提

- 用户需先在 mcpcat.cn 注册账号并在控制台生成 API Key，通过本连接器的凭证表单填入。
- 连接后请优先调用 `tools/list` 获取当前账号可用的工具清单（工具集随账号配置变化，本技能不预设固定数量），再按清单调用具体工具。

## 能力域（常见工具类别）

| 类别 | 典型能力 | 常见参数 |
| --- | --- | --- |
| 天气 | 城市/区域信息查询、未来多日天气预报 | 城市名或行政区划编码 |
| 物流 | 快递单号轨迹查询（顺丰/三通一达等） | 快递单号（部分需公司编码） |
| 网络工具 | DNS 解析查询、网站 HTTP 状态检测 | 域名 / URL |
| 生活信息 | 彩票开奖结果查询 | 彩种代码、期号（可选） |

具体工具名与参数以 `tools/list` 返回的 schema 为准，不要凭本表臆测参数名。

## 注意事项

- 需要先完成凭证填写；返回错误码 `-32001`（"API Key 无效或已停用"）时，引导用户到 mcpcat.cn 控制台重新生成并更新凭证，不要重复重试。
- 部分工具按次计费（以用户控制台展示为准）；调用前如有明显成本，告知用户。
- 查询类工具为只读操作，无副作用，可放心调用；涉及用户隐私数据的输入（如手机号、单号）仅用于当次查询。
- 天气/物流数据来自上游第三方服务，结果仅供参考，重要决策请交叉验证。

## 使用示例

用户："北京明天天气怎么样？"
→ 从 `tools/list` 中找到天气预报类工具 → 传入"北京"与日期 → 将结构化结果整理成自然语言回答。

用户："SF1234567890 到哪了？"
→ 找到快递查询工具 → 传单号 → 摘要最新轨迹节点与预计状态。

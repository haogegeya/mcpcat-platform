# 数据域目录（Tool Catalog）

> **不要在这里查工具名。** 工具名、参数 schema、价格的唯一可信来源是实时的 `tools/list`
> —— 用 [examples/count-tools.sh](../examples/count-tools.sh) 或直接在客户端里让 Agent 列出来。
>
> 本文定义的是平台的**数据域划分**：哪些世界事实属于平台的覆盖范围。

---

## 为什么要分域

聚合平台的扩张路径不是"随手接一个 API"，而是按域补齐。域定了，Agent 侧的期望就稳定了：
"查天气""查快递"这类需求，平台**必须有**一个可路由的 Capability。

## 数据域

| 域 | Capability 前缀 | 覆盖的世界事实 | 典型调用方 |
|----|-----------------|----------------|-----------|
| 🌤️ 生活服务 | `weather.*` | 实时天气、15 日预报、空气质量、生活指数 | 助手日报、出行决策、内容生成 |
| 📦 物流快递 | `express.*` | 单号轨迹、快递公司自动识别 | 客服 Bot、订单系统 |
| 📱 通信查询 | `phone_*` / `carrier_*` | 号码归属地、运营商三要素、携号转网 | 风控、表单校验 |
| 🌐 网络工具 | `dns_*` / `http_*` / `ip-*` | DNS 解析、HTTP 状态检测、IP 归属 | DevOps Agent、监控 |
| 💰 金融行情 | `finance-*` / `finance.*` | 贵金属、油价、汇率、A 股/基金、彩票开奖 | 量化辅助、资讯播报 |
| ✅ 验证核验 | `invoice_*` / `barcode_*` | 发票验真、条码信息 | 报销审核、零售 |
| 🚄 出行查询 | `train.*` / `holiday.*` | 余票/时刻、节假日与调休 | 日程助手、HR 系统 |

> 前缀风格（点号 / 下划线 / 连字符）在不同批次接入时未完全统一，**属历史遗留**。以实际返回值为准。

## 免费层

新用户注册即送 100 MCoin，且以下类型通常为**免费**（实时以 `tools/list` 标注为准）：

- 天气类基础查询（区域信息、多日预报）
- 网络诊断类（DNS 解析、HTTP 状态检测）
- 节假日 / 日历类
- 部分彩票开奖类

免费层的定位是**让 Agent 先跑通一次真实调用**，而不是提供长期白嫖配额。

## 请求新工具

平台按域补齐，优先级由真实调用量决定。提请求请给三件事：

1. **要什么数据**（例：某市地铁首末班车时刻）
2. **哪个 Agent 场景要用**（例：通勤规划 Bot）
3. **可接受的成本**（免费 / 几 MCoin 一次）

→ [开 Issue](https://github.com/haogegeya/mcpcat-platform/issues)

## 不在覆盖范围内

- 需要用户长期授权的企业内部系统（→ 用「自定义 Adapter」自建，平台只做转发归一）
- 强实时交易执行（下单、支付、转账）—— 平台是**读取**数据的接入层，不做资金动作
- 大模型推理类能力（→ 那是模型供应商的事）
